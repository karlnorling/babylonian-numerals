Babylonian Numerals

Draw any number the way Babylonian scribes pressed it into clay: corner wedges for tens, upright wedges for ones, in base 60. SVG with zero dependencies, plus PNG, JPEG and WebP.

Try any number

The playground draws whatever you type, breaks it into base-60 digits, and lets you download SVG, PNG, JPEG or WebP.

Base 60, exactly

Every decimal fraction is exact in base 60, and empty places get the late Babylonian placeholder. See how.

Zero dependencies

@babylonian/core turns a number into an SVG string in any JavaScript runtime.

Images and CLI

@babylonian/raster renders PNG, JPEG and WebP with sharp, and @babylonian/cli does it from the terminal.
