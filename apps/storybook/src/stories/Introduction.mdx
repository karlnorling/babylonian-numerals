# Babylonian Numerals

Stories for [`@babylonian/core`](https://www.npmjs.com/package/@babylonian/core), which renders any number as [Babylonian cuneiform numerals](https://en.wikipedia.org/wiki/Babylonian_cuneiform_numerals) in SVG.

- **Number Builder**: type any number in the `value` control and adjust every `toSvg` option.
- **Digits**: every digit from 0 to 59.

Corner wedges are tens and upright wedges are ones, so a digit runs from 1 to 59. Places count in sixties. Empty places get the late Babylonian placeholder, a dot marks the start of the fraction, and negatives start with a horizontal wedge.

For downloads and shareable links, use the [playground](../playground/) in the docs.
